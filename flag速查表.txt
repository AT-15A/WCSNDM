======================================================
 WCSNDM 引擎 Flag 速查表（写在 UTAU 音符的 Flags 栏）
======================================================
flag 可以连写组合，例如: Mt30Mf50g-10
大小写敏感: P 和 p 不同、Md 和 MD 不同。

------------------------------------------------------
一、先选"合成内核"（决定声音的基本质感）
------------------------------------------------------
(什么都不填)  = V2   默认，推荐日常使用（干净+有纹理）
K2            = 纯 LLSM2   可调参数最多〔旧名 L2，旧写法仍有效〕
K1            = 纯 LLSM1   干脆、干净（moresampler 同底座）〔旧名 L1〕
V1            = 混合       细节谐波 + 干净气声
M1            = 麦乐迪式   原始质感直出，几乎零合成感
                M1CR  = 瞬态更清晰版（长音会偏躁）
                M1l   = 长音推荐（循环延长，不发死）
HF            = 神经声码器（需装扩展，见 README）
HF2           = HF 的辅音清晰版 ★用 HF 时推荐填这个

------------------------------------------------------
二、最常用的几个（先记这些就够了）
------------------------------------------------------
g20 / g-20    变声。正=声音变厚变男，负=变细变女
              ±20 就很明显，最大 ±50
Mt40 / Mt-40  张力。正=紧、亮、有力；负=松、柔、暗
Mb30 / Mb-30  元音气声量。正=气多，负=气少(不碰清辅音)
Ab30 / Ab-30  全段气声量(连清辅音噪声一起动)
b-20 ~ b100   清辅音(s/t/k)音量。b-20=完全去掉 b30=加强
Mf50          高音救星：高音发虚时加，自动让声音"有芯"
              （低音自动几乎不起作用，可以常开）
MH30          高音太刺时加，压高频
P0            关掉音量归一化（默认每个音峰值统一拉满）

------------------------------------------------------
三、音色细调
------------------------------------------------------
Mo±100        开口度。正=嘴张大(亮透)，负=嘴收小(含蓄)
QX±100        共振峰锐化〔旧名ME,编辑器会拆坏,用QX〕。正=清晰有棱角，负=柔糊
Mr±100        3kHz"歌手共振峰"。正=加穿透力
Mu±100        鼻音度〔旧名 NA〕。正=鼻音/哼鸣感，负=去鼻音
Rd±100        声门松紧(只调声门不动音色包络)
A±100         颤音时音量跟着音高起伏(更自然的颤音)
Mp30          音高随机微抖，加"人味"
RG50/RG-50    自动混声：高音自动转头声/保持胸声(belt)，低音不受影响
Ms1~10        稳定化懒人包(=自动配平滑参数)

------------------------------------------------------
四、去杂音 / 降噪（声音"沙、糊、有颗粒"时用）
------------------------------------------------------
Mk50          去"糊/痰音"主力（默认已开25，可加大）
Mg50          去颗粒(时间方向平滑)
Mw24          去颗粒(频率方向平滑)，常和 Mg50 一起用
              ★推荐组合: Mw24Mg50
Mz50          降背景底噪
Mn50          气声脉动平滑。0=录音原样(默认)，50=适度平滑(旧版默认)，
              100=气声完全平稳，负值=脉动更深更颗粒
Mv60          去沙哑/磨圆长音（长音用60~70，短音可100）
JZ50          智能降噪(低质量素材救星)〔旧名 DN〕：修音高识别错
              +去录音底噪嘶声(从静音段学指纹，数值=强度，最大100)。
              自动识别素材干净程度，干净音源开了也无副作用
BX100         频宽扩展：压缩素材高频被砍(听着发闷)时自动补回
              空气带。好素材自动不动作。脏素材推荐 JZ50BX100
TM100         音色对齐：音源一半亮一半闷(混批次转录)时,把闷批次
              自动修成好批次的音色。批次统一的音源自动不动作
Mi100         神经蒸馏降噪(进阶)：需先用 tools/seed-vc 离线生成预设,
              之后零开销套用神经去噪。无预设自动不动作(见 README)

------------------------------------------------------
五、转音 / 特效
------------------------------------------------------
Mj4           转音平滑：转音/快速pitchbend处声音断裂或沙哑时用,
              自动修复。平缓音符不影响。写法 K2Mj4 / Mj4
MC0~100       粗糙感/沙嗓
MG0~100       低吼 growl
MD0~100       快速颤动式失真
（三个都是越大越强，可叠加，全内核可用）

------------------------------------------------------
六、时间控制
------------------------------------------------------
e             强制拉伸延长（不循环）
l             循环延长（长音更自然，M1 内核尤其推荐）
u             原样直出（不变调不拉伸，放气息音效用）
G             强制重新分析（换了音源文件时用一次）

------------------------------------------------------
七、常见问题速查
------------------------------------------------------
高音发虚没力气      -> Mf50 或 Mf100
高音刺耳            -> MH30
声音发糊            -> Mk50，还糊加 QX30
声音沙、有颗粒      -> Mw24Mg50
清辅音太吵          -> b-10；完全去掉用 b-20
素材音质差/嘶声底噪  -> JZ50~JZ100
声音发闷/高频缺失    -> BX100(压缩素材通病,自动检测)
音源音色不统一       -> TM100(一半亮一半闷的混装音源)
音高乱跳/破音       -> JZ1 起即可(修音高与数值无关)
低质素材一键组合     -> TM100JZ50BX100
想要气泡音/怒音     -> MG60MC30
长音发死、像电子音  -> 换 M1l 试试，或加 Mp20
想要最接近原声库    -> M1
想要最"AI感"的顺滑  -> HF2（需扩展）
