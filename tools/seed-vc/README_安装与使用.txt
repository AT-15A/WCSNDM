======================================================================
 WCSNDM 神经修复工具（进阶 / 可选，配合引擎 Mi、及音源整体修复）
======================================================================

这里只有两个"胶水脚本"，本体是开源项目 Seed-VC + 它的模型（约 4GB，
需自行下载）。普通调音【不需要】这些——引擎自带的 JZ/BX/TM 降噪补带已
覆盖大部分场景。只有想用神经网络做更强的人声修复时才装。

需要：NVIDIA 显卡（8GB 显存够用）、Python 3.10+、能联网下载模型。

----------------------------------------------------------------------
一、一次性安装
----------------------------------------------------------------------
1) 下载 Seed-VC 源码到本机某目录，例如 D:\seedvc ：
      git clone https://github.com/Plachtaa/seed-vc
2) 建独立虚拟环境并装依赖（不要污染系统 Python）：
      cd seed-vc
      python -m venv venv
      venv\Scripts\python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
      venv\Scripts\python -m pip install -r requirements.txt descript-audio-codec==1.0.0
3) 把本目录的两个 wcs_*.py 复制进 seed-vc 目录（与 inference.py 同级）。
4) 首次运行会自动从 HuggingFace 下载模型（约 4GB，断点续传）。
   国内网络若连不上，装 hf 镜像或用代理直连 huggingface.co。

----------------------------------------------------------------------
二、wcs_distill.py —— 生成 Mi 降噪预设（推荐，不新建 wav）
----------------------------------------------------------------------
把某音源的神经【去噪】效果蒸馏成逐帧参数预设（音源目录下每个 wav 旁
生成同名 .nfx，每个几十 KB）。之后 UTAU 音符填 Mi100 即零开销套用，
删 .nfx 或去掉 Mi 就完全回到原始。不改任何原始 wav。

  venv\Scripts\python wcs_distill.py --bank "F:\UTAU\voice\你的音源"
      [--skip-clean 28]   SNR 高于此的干净文件不生成预设（默认28）
      [--steps 30]        扩散步数
      [--limit N]         只处理前 N 个（调试用）

生成后，音符 Flags 填 K2Mi100（或 Mi100，默认 V2）即可。Mi50=半量。

----------------------------------------------------------------------
三、wcs_bank_restore.py —— 直接输出"修复版音源"（重武器，会新建音源）
----------------------------------------------------------------------
不走预设，直接把整个音源过一遍 Seed-VC，输出一个【新的修复版音源
文件夹】（oto 等配置自动复制、文件名不变、时长逐字节对齐）。适合追求
最强修复、不介意多一份音源的场景。

  venv\Scripts\python wcs_bank_restore.py --bank "F:\UTAU\voice\源" --out "F:\UTAU\voice\源_fix"
      [--ref self]   每文件用自己当参考=纯再生降噪(推荐,多人音源也适用)
      [--skip-clean 30] [--steps 30]

----------------------------------------------------------------------
分工提示
----------------------------------------------------------------------
- 去噪   → Mi（预设，轻）或 bank_restore（重）；引擎内 JZ 也能去噪
- 发闷/高频缺失 → 引擎 BX（不需要神经网络）
- 音源音色不统一 → 引擎 TM
神经工具擅长"去噪/再生级"修复；确定性的补带/音色对齐用引擎 flag 更快更稳。
