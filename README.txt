WCSNDM 测试版 beta3 (2026-07-13)
====================================

多内核 UTAU 重采样引擎:六个原生内核 + 可选神经声码器(HF)。
内置人声针对性修复:智能降噪 / 频宽扩展 / 音色对齐 / 转音平滑 / 神经蒸馏降噪。

【beta3 相对 beta2 的变更(2026-07-10 ~ 07-13)】
1. ME 改名 QX(共振峰锐化):原版 UTAU 编辑器会把 ME 拆成 M/E 两个
   flag 导致完全失效——务必用 QX。同时校准了可闻度(正向强度×2、
   逐点钳±12dB、噪声谱同步锐化,HF 模式下也明显可闻)。旧工程里的
   ME 在本引擎内仍识别,但会被编辑器改写,不要再用。
2. Mo(开口度)力度重标定为原 4 倍:旧工程如有 Mo,数值除以 4 等效。
3. Mn(气声脉动)重标定:现在 Mn0/不填=录音原样(旧版默认偷偷平滑了
   一半),Mn50=旧版默认听感,Mn100=完全平稳(旧版+50即饱和,现全程
   有效),负值脉动加深至2倍。想保持旧版出厂听感的工程补写 Mn50。
4. 新增诊断:每次调用在 exe 旁写 wcsndm_lastcall.txt(记录编辑器
   实际传入的 flags 串),排查"flag 没生效"时先看它。
5. 文档全面更新(docs\flag参数表 / flag速查表 / flag编辑逻辑表)。

【安装】
1. 本文件夹解压到任意位置(整个文件夹一起移动,exe 和 hf_backend 必须同目录)。
2. UTAU 工程设置:Tool2(resample)= 本目录 WCSNDM.exe。
   Tool1(wavtool)建议用 moresampler(自行下载)或默认 wavtool。
3. 直接使用即可(默认内核 V2,不需要任何 flag)。

【重要:2026-07 部分 flag 改名(旧写法引擎仍兼容)】
  内核  L1/L2 → K1/K2   (L 与 resampler 系引擎冲突)
  降噪  DN    → JZ       (N 被 UTAU 编辑器当无值 flag、会吃掉数字)
  鼻音  NA    → Mu       (同上)
  锐化  ME    → QX       (E 同上;且编辑器会把 ME 拆成 M/E 使其失效,
                          这个必须用新名,旧名在编辑器里根本传不进引擎)
新工程请一律用新名。

【合成内核选择(Flags 栏)】
(不填)= V2 默认   |  K2 / K1 / V1 = 其它原生内核
M1 = 麦乐迪式时域内核(M1CR=crisp)
HF / HF2 = 神经声码器(需下方扩展环境;HF2=辅音清晰版,推荐)

【人声修复 flag 速览(低质量素材/鬼畜素材)】
JZ50~100   智能降噪:修音高识别错误 + 去底噪嘶声(从静音段学指纹)
BX100      频宽扩展:补回被压缩砍掉的高频"空气带"(听着发闷时用)
TM100      音色对齐:音源一半亮一半闷(混批次转录)时统一音色
Mj4        转音平滑:转音/快速 pitchbend 处声音断裂沙哑时修复
Mi100      神经蒸馏降噪(进阶,需先离线生成预设,见 tools\seed-vc)
以上都会自动判断素材、干净音源开了无副作用,可整曲常开。
低质素材一键组合: JZ50BX100  (或加 TM100)
完整 flag 说明见 docs\flag参数表.txt(通俗版)/ flag参数表.md(权威版)、flag速查表.txt

【HF 神经声码器扩展(可选)】
需要:1) 安装 Python 3.10+ 并加入 PATH
     2) 命令行执行: pip install torch soundfile scipy numpy
装好后音符 flags 填 HF 或 HF2 即可;第一个音符会自动启动后台服务(约20秒,仅每次开机一次),
之后每音符约 1 秒。不装扩展不影响其它内核。
后台服务进程名 pythonw,可在任务管理器结束(下次使用自动重启)。

【神经修复工具(可选,进阶)】
tools\seed-vc\ 下有两个脚本 + 说明:用 Seed-VC 做更强的神经去噪
(生成 Mi 预设,或直接输出修复版音源)。需 NVIDIA 显卡。
普通调音不需要——引擎自带的 JZ/BX/TM 已覆盖大部分场景。详见该目录 README。

【缓存说明】
引擎会在声库目录生成 .llsm2 / .l1f0 缓存(加速二次渲染)、TM 建的
wcsndm_bank.prof(音色档案)、Mi 用的 .nfx(神经降噪预设)。均可随时删除。

【已知事项】
- 默认 V2 内核每音符跑双分析(约 2 倍耗时),追求速度可显式填 K2。
- HF 的辅音由 mel 分辨率限制,建议用 HF2。
- M1 长音建议 M1l(循环模式);M1 不支持 Mf/BX/TM/Mi 等谱域 flag。
- 48kHz/立体声音源自动重采样到 44.1kHz 单声道(与 UTAU 生态一致)。
