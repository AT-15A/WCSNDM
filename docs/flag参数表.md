# WCSNDM(原llsm_utau) 引擎 Flag 参数表

> 全部 flag 的权威清单(名称/范围/默认/作用/适用内核)。历史与实验过程见《进度记录_音质逼近mo.md》。
> 最后更新:2026-07-06d(改名 K1/K2/JZ/Mu[避编辑器冲突,旧名兼容];JZ 智能降噪栈;BX 频宽扩展;TM 音色对齐;全内核统一输出 44.1k)

flag 写在 UTAU 音符 **Flags** 栏,可组合(如 `Mt30Mf50g-10`)。大小写敏感(`P`≠`p`,`Md`≠`MD`)。

> **2026-07-06 改名**(避开原版编辑器/resampler 系冲突):内核 `L1/L2`→**`K1/K2`**(L 撞引擎系 flag)、
> `DN`→**`JZ`**、`NA`→**`Mu`**(原版编辑器把 N 当无值 flag 回写会吃掉后面的数字)、
> `ME`→**`QX`**(2026-07-12:编辑器把 E 当已知 flag,ME 被拆成 M/E 致编辑完全丢失)。
> **旧写法仍被引擎兼容接受**,已有 UST 不受影响;新工程请用新名。

## 〇、合成内核(先选模式,再配 flag)

| 填法 | 内核 | 谐波 | 噪声 | 一句话 |
|---|---|---|---|---|
| **(不填)** | **V2** | L1 | L2 | 默认最佳:L1 稳谐波+L2 噪声纹理(跑两遍分析,≈2×耗时) |
| `K2`(旧`L2`) | 纯 LLSM2 | L2 | L2 | 全功能主引擎,把手最多 |
| `K1`(旧`L1`) | 纯 LLSM1 | L1 | L1 | mo 同底座,干脆干净 |
| `V1` | 混合 | L2 | L1 | L2 谐波细节+L1 干净噪声 |
| `M1` | 麦乐迪式(TD-PSOLA) | 时域 | 时域 | 零模型误差原始质感;`M1CR`=crisp(瞬态型),默认 smooth |
| `HF` | 神经声码器 | mel→NSF-HiFiGAN | 同左 | 编辑后参数→logmel→HiFiGAN;首音符~20s 拉 daemon,之后~0.9s/音符 |
| `HF2` | 杂交 | 辅音=V2时域 / 元音=HF | 同左 | **辅音清晰版 HF**:辅音固定区用 V2 渲染(瞬态100%保真,实测4-12k能量追平V2),元音用 HF。拼接v3(2026-07-07):相位对齐+拼接点邻域局部RMS匹配+测量驱动响度整形(5ms粒度校正到两端锚点dB线性过渡,±3dB封顶)——修复拼接区隆起/凹陷/台阶。推荐日常用这个 |

> 缓存:L2 用 `<wav>.llsm2`、L1/M1 共享 `<wav>.l1f0`、mo 自己的 `.llsm` 互不冲突。`G` flag 强制重分析(.llsm2)。
> 推荐工具位:Tool1(wavtool)=moresampler(拼接好)、Tool2=WCSNDM.exe。HF 后端在 F:\UTAU\hf_backend\(自动拉起)。

## 一、音量 / 输出

| flag | 范围 | 默认 | 作用 | 适用 |
|---|---|---|---|---|
| `P` | 0~100 | **100** | 峰值归一化到 0.5,`(0.5/峰)^(P/100)`。P0=关(保留原始动态) | 全内核 |
| `p` | −1~6 dB | 关 | 最终峰值再归一,越大越安静 | L2/V |
| `SK` | 开关 | 关 | 极性反相(对齐 mo 波形约定,基本不可闻) | 全内核 |

## 二、音高 / 时间

| flag | 范围 | 默认 | 作用 | 适用 |
|---|---|---|---|---|
| `t` | ±1200 cents | 0 | 音高微调(100=1半音) | 全内核 |
| `Mp` | 0~100 | 关 | 音高随机扰动(带限~100ms,满量程±25c),加人味 | 全内核 |
| `Mi` | 0~100 | 关 | **神经蒸馏降噪预设**:把离线神经修复(Seed-VC self-ref 等)的**去噪**效果蒸馏成逐帧 64 带噪声谱(psd)差量(`<wav>.nfx`,截止以上自动 taper 归零留给 BX),渲染时按强度叠加到源 chunk 的 psd。纯参数微秒级、每文件几十 KB、强度可调、可逆(删 .nfx/关 Mi 即回原始)。实测参数域复现 0.40dB、渲染无伪影、方向正确、强度线性。只蒸 psd(去噪的全部作用所在,gauge-free);谐波音色 vt 与逐帧 Rd 纠缠无法单独移植,self-ref 降噪本不改音色故置零无损。工具:tools/seed-vc/wcs_distill.py。无 .nfx 自动不动作 | K2/L2/V1/HF(源 chunk 噪声谱);M1 时域无 |
| `Mj` | 1~6 | 关 | **转音平滑**:快速 pitchbend 下,谐波合成的"每帧恒定频率阶梯"在帧重叠处失相位相干,中高谐波出断点/沙哑(误差∝(k+1)·df0/dt·thop²)。加密合成帧 thop/F→误差降 1/F²。值=加密上限 F,自动按音高斜率取 1~F(峰值>0.4 半音/hop 才启用);**平缓音符 F=1 不掉速**。实测 4-8k 最坏断口 K2 −4dB、K1 −6.6dB | **K2/V1/K1/V2 全覆盖**(L2 与 L1 两条谐波路径各按自身 hop 独立加密);M1 时域无此问题、HF 神经声码器不介入 |
| `e` | 开关 | — | 强制拉伸(不循环) | L2/V/L1 |
| `l` / `Me` | 开关 | — | 循环模式(Me=mo 语义同义词) | L2/V |
| `u` | 开关 | 关 | 直出:oto 区段原样输出(不变调不伸缩),气息/音效用 | 全内核(优先级最高) |
| `G` | 开关 | — | 强制重分析、覆盖 .llsm2 缓存 | L2/V |
| `CR` | 开关 | 关 | M1 内核切 crisp(小窗吸附:瞬态清,长音躁) | 仅 M1 |

|---|---|---|---|---|

| `QX`(旧`ME`) | ±100 | 0 | 共振峰强调/清晰度(unsharp,±1200Hz趋势):正=偏差×(1+2v)锐化,负=向趋势压平(-100=完全压平,物理极限);单点修正钳±12dB(防谷区崩坏);**同一 unsharp 同步作用噪声 psd**(否则谷被噪声底填回,HF 尤甚)。[2026-07-12 四轮:HF 实测±100共振峰区+3~5dB/F1下16dB/高频7dB,K2 F1下30dB。日常±30~60] | 除 M1 全内核(HF 实测生效) |

## 四、噪声 / 气声 / 辅音

| flag | 范围 | 默认 | 作用 | 适用(噪声来自 L2:缺省V2/L2;来自 L1:L1/V1) |
|---|---|---|---|---|
| `Mk` | 0~100 | **25** | 子谐波抑制(去糊/去痰,频率加权:低频重压高频留空气)。去糊主力 | L2 噪声 |
| `Mg` | 0~100 | 关 | 噪声时间平滑(源侧,去帧间颗粒);建议 50 起 | L2 噪声 |
| `Mw` | 8~48 | 关 | 噪声频率 constant-Q 平滑+丢残差;**推荐 `Mw24`+`Mg50~100`**;≤8 会出沙声 | L2 噪声 |
| `Mz` | 0~100 | 0 | 降噪(谱减背景底噪) | L2 噪声 |
| `JZ`(旧`DN`) | 0~100 | 关 | **智能降噪栈**(修复低质量素材):≥1 启用。层①=f0 轨迹人声先验修复(八度错/野点/漏检,与数值无关);层②=嘶声印记降噪(强度=DN 值)——静音帧提取常驻底噪谱,(a)谱减噪声 psd,(b)对被谐波分析拟合成高次"谐波"的嘶声轨迹按印记恒定增益压制(自校准+SNR 门控,干净素材自动零动作)。样本需含静音段,无静音时层②自动跳过。实测金坷垃 shim:8-12.5k 嘶声 -5dB,人声主体 0 变化;干净素材各层全零动作,可常开。低质素材建议 DN50~100 | 全内核(层② V2/L2/V1/HF;L1/M1 仅层①) |
| `BX` | 0~100 | 关 | **频宽扩展**(修压缩素材发闷):自动检测编解码高频截止悬崖(平均谱宽窗落差≥18dB,金坷垃全员~12.7kHz),把截止以上空气带按崖前真实谱斜率逐帧线性外推补齐(源区间避开低通过渡带;斜率钳[-6,-1.5]dB/kHz;只补噪声分量不造谐波=无金属声)。值=补带电平(100=自然斜率,50≈-6dB)。检测在 DN 之前原始谱上做,填充在 DN 之后。全频段素材自动不动作可常开;脏素材推荐 `JZ50BX100` | V2/L2/HF(V1/L1/M1 噪声不走 L2) |
| `TM` | 0~100 | 关 | **音色对齐**(修混批次音源,说话人先验第一档):按录音批次(源采样率+声道=转录代际指纹)分组,组均 LTAS 相减=纯通道染色(整套音素两侧抵消,不动音素身份),把当前批次 EQ 回最亮批次,同时作用谐波包络+噪声 psd。<800Hz 保护;死带(缺口>25dB)斜坡归零=让给 BX;钳±10dB+±2带平滑。首次建档扫全文件夹(数秒,缓存 `wcsndm_bank.prof`,`G` 强制重建);单一批次或批次差<1dB 自动不动作。实测合成混批库:过渡带 +5dB 复原,音素主体 0 变化(V2/L1 一致) | V2/L2/V1/L1/HF(仅 M1 不适用:时域无谱参数) |

## 七、快速配方

- 日常干净:缺省(V2)即可;偏沙加 `Mw24Mg50`,偏糊加 `Mk50`
- 高音发虚:`Mf50~100`;高音刺:`MH30`
- 变声:`g±20`;更开/闭:`Mo±40`;紧张/松弛:`Mt±40`
- 人味:`Mp30A50`;怒音:`MG60MC30`
- 原始质感直出:`M1`;神经纹理:`HF`(可全组合如 `HFMt30Mf50`)
