==================================================================
 WCSNDM 引擎 可用 Flag 一览（名称 / 效果 / 支持模式）
==================================================================
写在 UTAU 音符 Flags 栏，可连写组合（如 Mt30Mf50g-10）。
大小写敏感（P≠p、Md≠MD）。

模式代号: V2=默认(不填)  K2  K1  V1  M1  HF(/HF2)
【2026-07-06 改名】K1/K2(原 L1/L2)、JZ(原 DN)、Mu(原 NA)——
避开原版编辑器和 resampler 系引擎的 flag 冲突。旧写法仍然有效。

------------------------------------------------------------------
【内核选择】
------------------------------------------------------------------
(不填)     默认内核 V2（稳谐波+纹理噪声，日常推荐）
K2         纯 LLSM2 内核（可调项最多）〔旧名 L2〕
K1         纯 LLSM1 内核（干脆干净）〔旧名 L1〕
V1         混合内核（K2谐波+K1噪声）
M1         麦乐迪式时域内核（原始质感，几乎零合成感）
CR         M1 专用开关：切 crisp 模式（瞬态清晰，长音偏躁）
HF         神经声码器内核（需扩展环境）
HF2        HF 辅音清晰版（辅音走时域渲染，推荐代替 HF）

------------------------------------------------------------------
【音量 / 输出】
------------------------------------------------------------------
P    0~100   峰值归一化强度，默认100=每音峰值统一。P0=保留原始动态
             支持: 全部模式
p    -1~6    最终峰值再压低(dB)，越大越安静
             支持: V2 K2 V1
SK   开关    波形极性反相（听感几乎无变化）
             支持: 全部模式

------------------------------------------------------------------
【音高 / 时间】
------------------------------------------------------------------
t    ±1200   音高微调，单位cent（100=1半音）
             支持: 全部模式
Mp   0~100   音高随机微抖（加"人味"，满量程约±25cent）
             支持: 全部模式
Mj   1~6     转音平滑：快速pitchbend/转音处中高谐波会断裂/沙哑，
             自动加密合成帧修复。值=加密上限(常用Mj4)，平缓音符
             自动不加密、不掉速。写法 K2Mj4 / Mj4
             支持: V2 K2 V1 K1（M1/HF 不需要）
e    开关    长音强制拉伸（不循环），与 l 同时填时 e 优先
             支持: V2 K2 V1 K1 M1
l    开关    长音循环延长（折返播放真实录音，长音更自然）
             支持: V2 K2 V1 M1
Me   开关    同 l（moresampler 兼容写法）
             支持: 同 l
u    开关    原样直出：不变调不拉伸，直接输出 oto 区段（放气息/音效）
             支持: 全部模式（优先级最高）
G    开关    强制重新分析、刷新缓存（更换音源文件后用一次）
             支持: V2 K2 V1

------------------------------------------------------------------
【音色 / 共振峰】
------------------------------------------------------------------
g    ±50     变声（共振峰整体移动）。正=厚/男声化，负=细/女声化。
             ±20 即明显，±50 满量程
             支持: 全部模式
Mo   ±100    开口度。正=嘴张大（亮、透），负=收小（含、闷）
             支持: 全部模式
Mt   ±100    张力。正=紧、亮、硬；负=松、柔、暗
             支持: 全部模式
Rd   ±100    声门松紧（只改发声源，不动音色包络）。正=紧
             支持: K2 V1 HF
Mf   0~100   共振峰自动调谐：高音自动"有芯"，深降调自动去轰。
             小幅变调时自动不起作用，可常开。建议 50 起
             支持: V2 K2 V1 K1 HF
QX   ±100    共振峰锐化〔旧名 ME,原版编辑器会拆坏 ME,请用 QX〕。
             正=清晰有棱角，负=柔和模糊(-100=完全压平)
             支持: V2 K2 V1 K1 HF
Mr   ±100    3kHz 歌手共振峰。正=加穿透力/亮度
             支持: V2 K2 V1 K1 HF
MH   ±100    高频倾斜。正=压高频（高音不刺）；向上变调时自动启用
             支持: V2 K2 V1 K1 HF
A    ±100    颤音音量联动：音高起伏时音量跟着起伏（自然颤音）
             支持: V2 K2 V1 K1 HF
Mu   ±100    鼻音度〔旧名 NA〕。正=更鼻音(闭口哼鸣,500Hz反共振)，负=去鼻音
             支持: V2 K2 V1 K1 HF
Mm   0~100   模型插值：0=纯L1音色 ←→ 100=纯L2音色
             支持: 仅 K2（写法如 K2Mm30）
RG   ±100    自动混声：按音高自动渐变声区(换声点F4,平滑过渡)。
             正=高音自动转头声(柔/暗/带气)，负=高音保持胸声(belt,紧亮)。
             低音区自动几乎不起作用，可整曲常开。建议 ±40~70
             支持: V2 K2 V1 K1 HF
Ms   0~10    稳定化懒人包（自动配置 Mv/MS 平滑）
             支持: K2 V1

------------------------------------------------------------------
【噪声 / 气声 / 辅音】
------------------------------------------------------------------
Mk   0~100   去"糊/痰音"（默认已开25，声音糊就加大）
             支持: V2 K2 HF
Mg   0~100   去颗粒·时间方向（沙沙颗粒感），建议 50 起
             支持: V2 K2 HF
Mw   8~48    去颗粒·频率方向（值=带数，越小越平滑，别低于8）。
             推荐与 Mg 组合: Mw24Mg50
             支持: V2 K2 HF
Mz   0~100   降背景底噪
             支持: V2 K2 HF
JZ   0~100   智能降噪(修低质量素材)〔旧名 DN〕：≥1 启用。①自动修
             音高识别错误(八度跳/野点/漏检) ②自动降录音底噪/嘶声
             ——从样本静音段学底噪指纹,数值越大越强,建议 50~100。
             自动识别素材干净程度,干净音源开了无副作用,可整曲常开
             支持: 全部模式(降噪主力在 V2/K2/V1/HF;K1/M1 只修音高)
BX   0~100   频宽扩展(修压缩素材发闷)：自动检测高频被编码截断的
             素材(如12.7kHz悬崖),按真实频谱斜率补回缺失的高频空气
             带。100=自然电平。全频段好素材自动不动作,可常开。
             脏素材推荐组合: JZ50BX100
             支持: V2 K2 HF
TM   0~100   音色对齐(修混批次音源)：音源一半亮一半闷(不同来源的
             转录混装)时,自动按批次(采样率/声道)分组,把闷批次的
             音色 EQ 回好批次。首次使用扫全文件夹建档(几秒,自动
             缓存)。批次统一的音源自动不动作。可配: TM100JZ50BX100
             支持: V2 K2 V1 K1 HF(仅 M1 不支持)
Mi   0~100   神经蒸馏降噪(进阶,需先离线生成预设)：把 Seed-VC 等
             神经修复的"去噪"效果烘成逐帧预设(音源目录下 .nfx),
             渲染时按强度叠加,纯参数零开销。无预设自动不动作,删
             .nfx/去 flag 即回原始。预设由 tools/seed-vc 生成(见
             README)。值=强度,Mi100满量/Mi50半量
             支持: V2 K2 V1 HF(源噪声谱;M1 时域无)
Mn   ±100    气声脉冲平滑（帧内去颗粒）。0=录音原样，Mn50=适度平滑
             （旧版默认），Mn100=气声完全平稳，负=脉动加深更颗粒
             支持: V2 K2 HF
Md   ±100    干燥度：正=高频气声纹理更多，负=更干（效果微妙）
             支持: V2 K2 HF
Mb   ±100    元音气声量（只作用于元音/浊音段）。正=气多，负=气少(±12dB)
             支持: V2 K2 V1 K1 HF
Ab   ±100    全段气声量（元音+清辅音一起，含 s/t/k 的噪声）±12dB
             支持: V2 K2 V1 K1 HF
b    -20~100 清辅音(s/t/k等)音量。b-20=完全去除，b30=加强
             支持: 全部模式
bh   -20~100 辅音段的"嗓音"部分音量（浊辅音 m/n/l 等）。bh-20=近静音
             支持: 全部模式
Mv   0~100   去沙哑/磨圆（长音建议60~70，短音可100）
             支持: K2 V1
MS   0~100   参数时间平滑（动态内容更稳）
             支持: K2 V1 HF
LD   0~100   包络降维（轻微磨圆脉冲，可用区40~80）
             支持: K2 V1 HF

------------------------------------------------------------------
【特效】
------------------------------------------------------------------
MC   0~100   粗糙感/沙嗓（逐周期随机起伏）
             支持: 全部模式
MG   0~100   低吼 growl（半频律动）
             支持: 全部模式
MD   0~100   快速颤动式失真（比 MG 抖得快）
             支持: 全部模式

------------------------------------------------------------------
【诊断用（一般不用）】
------------------------------------------------------------------
Mx   1或2    只听谐波(1)/只听噪声(2)，排查问题用     支持: 仅 K2
PB   开关    逐脉冲合成实验路径（偏粗糙）             支持: 仅 K2
Ma   0~100   抗失真（价值低，不推荐）                 支持: K2系
