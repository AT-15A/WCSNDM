## 一、四种模式怎么选

| 模式 | 触发 | 谐波来自 | 噪声来自 | 一句话 |
|---|---|---|---|---|
| **V2** | **默认(不填任何模式flag)** | **L1** | **L2** | L1 稳谐波 + L2 噪声纹理（**当前默认/最佳**） |
| **L2** | `L2` | L2 | L2 | 全功能主引擎,把手最多 |
| **L1** | `L1` | L1 | L1 | mo 同底座,干脆干净,把手少 |
| **V1** | `V1` | **L2** | **L1** | L2 谐波细节 + L1 干净噪声 |

> **⚠ 默认已改为 V2**：不填任何模式 flag = V2 混合。要回到纯 L2 请显式填 `L2`。
> (每次渲染缺省会同时跑 L2+L1 两次分析,约 2× 耗时——V2 混合的代价。)

## 二、核心规律(记住这条就够)

- **谐波类 flag** → 在"**谐波来自哪个库**"的模式里生效；
- **噪声类 flag** → 在"**噪声来自哪个库**"的模式里生效；
- **全局类**(音量/极性/音高/时间) → 各模式基本通用。

> 推论：V1 能编辑谐波(L2 全套)但噪声几乎不可编(用 L1 干净噪声)；V2 反过来——谐波只能用 L1 那几个(g/Mo/ME/Mr)，但噪声可用 L2 全套。

## 四、实用建议

- **要最多可编辑性** → `L2`(全套 flag) 或 `V1`(谐波全套可编 + 干净噪声)。
- **要干脆干净、少调** → `L1` 或 `V2`。
- **`V2`(当前最佳)想调音色**：谐波用 `g/Mo/ME/Mr`；噪声用 `Mb/b/Mn/Mz/Mk/Mg/Md`。例:`V2g-100Mr40Mk50`。
- **`V1` 想调音色**：谐波用 L2 全套(含 `Mt/Mv/A/MH…`)；噪声基本别指望(L1 已干净)。
- `Mc`/`PB`/`Mx` 请只在纯 `L2` 下用,不要和 `V1/V2` 混。
